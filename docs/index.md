# ligo Provider

The provider of ligo, the SPIFFE binding lifecycle service. It files change requests through ligo's admin API and waits for them; it never approves one.

The provider manages the resources of [ligo](https://github.com/dihedron/ligo), the SPIFFE binding lifecycle service: sources, targets, bindings, and the platforms, identity providers and secret stores that serve them. It works the same with Terraform and with OpenTofu.

## How it works

- **Every change is a change request.** The provider files it once and waits for it. It never approves, declines or ratifies anything: that is people's work, and the provider has no call that does it.
- **A run can wait.** A pipeline that is trusted automation (a SPIFFE identity registered as such) is approved by delegation, with `approval_reference`. A person, and every change to a platform, an identity provider or a secret store, waits for an approver; the apply ends at `approval_timeout` with the request still open, and the next apply waits for that same request instead of filing another.
- **The lock.** What the provider files for trusted automation is *managed*: only that automation changes it, and people cannot (except a binding, through break-glass). `managed = false` on a resource releases it.
- **Nothing secret is stored.** No attribute holds a password or a token; an instance's `config` names its credentials by reference and is sensitive.

## Versions

The provider supports the `ligo` version whose client it is built with (v0.7.0) and the next minor version. A `ligo` that is too old or too new for a call answers with a problem, which the provider shows as it is.

## Example Usage

```terraform
terraform {
  required_providers {
    ligo = {
      source = "dihedron/ligo"
    }
  }
}

# A pipeline: it authenticates with its SPIFFE identity (X.509-SVID from the
# Workload API) and verifies the server by its SPIFFE ID. Trusted automation
# owns what it files (the lock, managed = true by default) and approves by
# delegation, which needs the upstream record in approval_reference.
provider "ligo" {
  server_url         = "https://ligo.example.org:9443"
  spiffe_socket      = "unix:///run/spire/agent.sock"
  server_id          = "spiffe://prod.example.org/ns/sys/sa/ligo"
  approval_reference = "CHG-0001"
  approval_timeout   = "10m"
}

# A person: LDAP Basic credentials, the password read from a private file
# (never from the configuration). A person cannot own a resource, so every
# resource needs managed = false, and a change waits for an approver.
provider "ligo" {
  alias         = "person"
  server_url    = "https://ligo.example.org:9443"
  ca_cert       = "/etc/ligo/ca.pem"
  username      = "olivia"
  password_file = "/home/olivia/.ligo/password"
  managed       = false
}
```

## Schema

### Optional

- `approval_reference` (String) The upstream change record (a ticket, a pipeline run) sent with every filing; ligo requires it for a delegated approval.
- `approval_timeout` (String) How long a write waits for its change request, a duration such as 10m (the default); at most 24h. A request that is still pending then is an error; it stays in ligo and may still be approved.
- `automation_context` (Map of String) Who runs the automation (job, workspace, run URL), recorded by ligo for traceability; never used for authorization.
- `ca_cert` (String) A path to a PEM bundle that verifies the server, instead of the Workload API's bundle (or, with credentials, the system's roots).
- `managed` (Boolean) The default of every source, target and binding: true (the default) files them as managed by this automation, so that only it changes them (the lock). Each resource's own managed overrides it. A run with username is a person and cannot own: set it to false.
- `password_file` (String) A file that holds the LDAP password and that nobody but its owner may read. There is no attribute that holds the password.
- `server_id` (String) The SPIFFE ID ligo must present when it is verified against the bundle of the SPIFFE Workload API. Default: spiffe://<the caller's trust domain>/ns/sys/sa/ligo.
- `server_url` (String) The admin API, an https:// URL. Environment: LIGO_SERVER_URL.
- `spiffe_socket` (String) The SPIFFE Workload API socket; the provider presents the caller's SVID over mTLS. Environment: SPIFFE_ENDPOINT_SOCKET.
- `username` (String) An LDAP user, with password_file, when there is no Workload API. A person is never trusted automation: every write waits for an approver.
